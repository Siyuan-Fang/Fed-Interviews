# Shared Data

Data in this directory is shared by Table 1 and Table 2.

## Directory contents

```text
Data/common/
├── events/       # announcement and interview lists
├── raw/          # raw futures data used to regenerate matched files
├── matched/      # matched intraday event windows
└── auxiliary/    # macro data release times
```

## Matched files

There are 20 matched files: five event types by four assets.

| Event type | ED2 | ED3 | ED4 | SP500 |
|---|---|---|---|---|
| FOMC announcements | `fomc_announcementED2.csv` | `fomc_announcementED3.csv` | `fomc_announcementED4.csv` | `fomc_announcementSP500.csv` |
| Chair speeches | `baha_powell_79ED2.csv` | `baha_powell_79ED3.csv` | `baha_powell_79ED4.csv` | `baha_powell_79SP500.csv` |
| Interviews top 100 | `interviews_top100ED2.csv` | `interviews_top100ED3.csv` | `interviews_top100ED4.csv` | `interviews_top100SP500.csv` |
| Interviews top 200 | `interviews_top200ED2.csv` | `interviews_top200ED3.csv` | `interviews_top200ED4.csv` | `interviews_top200SP500.csv` |
| Minutes | `minutesED2.csv` | `minutesED3.csv` | `minutesED4.csv` | `minutesSP500.csv` |

Each matched file has these columns:

- `15bf`: start of the event window
- `Datetime`: timestamp of the matched starting price
- `CLOSE`: starting price
- `75aft`: end of the event window
- `Datetime2`: timestamp of the matched ending price
- `CLOSE2`: ending price
- `Publish_Times`: announcement time in UTC
- `title`: event title
- `change`: log difference `log(CLOSE2) - log(CLOSE)`

## Upstream lineage

```text
events/*.csv
    +
raw futures ED2.csv / ED3.csv / ED4.csv / SP500.csv
    +
auxiliary macro release times
    |
    v
Code/table1/generate_matched.py
    |
    v
matched/*.csv
    |
    +--> Code/table1/run_table1.py --> Tables/table1/
    |
    +--> Code/table2/run_table2.py --> Tables/table2/
```

The matched files can be regenerated by `Code/table1/generate_matched.py`.

## Raw futures data

`Data/common/raw/{ED2,ED3,ED4,SP500}.csv` are intraday futures files from a
commercial vendor. They total roughly 380 MB and exceed GitHub's 100 MB
per-file limit, so they are excluded by `.gitignore`.

They are needed **only** to regenerate `Data/common/matched/`, which is
committed. Every table and figure in this package reproduces from the matched
files alone.

The FOMC matched files use a window of 10 minutes before to 20 minutes after
the announcement.
