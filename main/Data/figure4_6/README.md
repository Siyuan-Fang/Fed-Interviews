# Figures 4–6 Data

## Regression inputs

| File | Figure | Obs | Event type |
|---|---|---:|---|
| `reg_baha_powell_79.csv` | Figure 4 | 79 | Fed Chair speeches |
| `reg_interview_top100_without200402.csv` | Figure 5 | 99 | Fed Presidents interviews, top 100 |
| `reg_interviews_top200.csv` | Figure 6 | 200 | Fed Presidents interviews, top 200 |

Each file has one row per announcement window with columns `date`, `MP1`,
`ED2`, `ED3`, `ED4`, `SP500`, `transfact1`, `TFUT02`, `TFUT10`. The MATLAB
estimation reads only `TFUT02` and `SP500`.

Note the Figure 5 file name: the top-100 sample used for the figure **excludes
the 2004-02 observation**. The unfiltered `reg_interviews_top100.csv` is not
used here.

## Column construction

`ED2`–`ED4` and `SP500` come from the same matched event windows as
[`Data/common/matched/`](../common/matched/), scaled by 10000. All series
except `SP500` have their sign flipped so that a positive value is a rate
increase.

`TFUT02` and `TFUT10` are Treasury futures yields converted to a per-period
basis:

```text
TFUT02 = ((1 + yield/100)^(1/2)  - 1) * 100
TFUT10 = ((1 + yield/100)^(1/10) - 1) * 100
```

These two columns, along with `MP1` and `transfact1`, were prepared separately
from the Python pipeline in this package and are committed here as the
authoritative copies.

## Estimation output

```text
figure4_maxl.mat
figure5_maxl.mat
figure6_maxl.mat
```

Each holds a `maxl` struct with the estimated impact matrix `C`, its inverse
`W`, the extracted shocks `U` (plus `U1s`, `U1bp` normalizations), the
degrees-of-freedom vector `v`, the log-likelihood `ll`, the Hessian, and the
variance decomposition `vdec`.

Generated by [`Code/figure4_6/run_figures_4_5_6.m`](../../Code/figure4_6/run_figures_4_5_6.m).
